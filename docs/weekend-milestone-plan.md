## Scope and dependencies

- Sketchfab character review still precedes workshop production, but does not block the website, guide foundations, Design or Product work.
- Current ComfyUI package supports media generation, not 3D mesh creation. Verify that separate route early. Do not claim production integration from offline tests alone.
- Use one corner, one teacher, three instruments and a fixed/limited camera. No campus, multiplayer, accounts, live AI chat, backend progression or native Quest app this weekend.
- Animation can be represented by pose/timing direction and a short study; Cards and Rewards can be represented by designed targets rather than invented gameplay systems.
- Quest preview, secondary faculty audio, lip sync, rigging and detailed effects are the first cuts. Protect the coherent guide, visual scene, complete pitch and finish time.
- Only presentation-site/dist is deployed as public website content. Original research, workflow files, voice settings, character registry, source artwork and .git stay outside it.
- Local sources reflect the latest male Goblin correction. Historical documents and exports may retain earlier wording until explicitly regenerated; use current roster/canon for future outputs.

## Delivery route

Web first with an eventual Meta Quest Browser/WebXR path. Reuse assets and activity logic; plan controller selection, world-scale interface and actual headset performance testing later.
