# Project instructions

## Publishing approval

- Ask the user before publishing or deploying changes. A request to edit the site is not permission to publish it.
- Do not push to `main` or any deployment-triggering branch without explicit approval for the concrete, reviewed result.
- Reconcile concurrent local changes, including the Art Style Guide's Environment and Animation sections, and verify a local preview before asking to publish.

## Existing exterior artwork

- Reuse the project's existing exterior concepts. Do not generate new exterior images unless the user discusses and authorizes that work again.

## 3D modeling capability and quality

- Before starting future 3D modeling work, candidly explain whether the available tools and capabilities can achieve the requested quality and fidelity to the reference.
- If the result would be limited to primitive-based construction or a similarly limited procedural approximation, disclose that limitation before doing the work. Do not imply that this will deliver the requested professional character modeling quality.
- If the requested model or quality is not achievable with the available capabilities, say so before proceeding and let the user decide how to continue.
- The user rejected the generated goblin music teacher model as unacceptable. Treat it as a failed quality reference, not an approved art direction or modeling standard for this project.
