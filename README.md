# VRSchool

A virtual reality school concept where students learn from friendly fantasy creatures inspired by Dungeons & Dragons. Teachers use puzzles, games, interactive activities, and collaborative projects in themed learning environments.

The original materials use the name **VRSchool**; this project is also referred to as **VRHS** (virtual reality high school).

## Current status

This repository gathers the existing concept documents and recovered reference materials. It does not yet contain a playable application or a selected development stack.

The recovered Photoshop composite is an AI tools infographic. New character concepts now explore the user's existing geometric game styles, Bizzy Dad Organizer's painted style, and Arthur's own pencil drawings. Detailed block forms are an accepted option; a simpler version with larger primitives and blank faces is also included. A final production style has not yet been selected.

See the [project status](docs/project-status.md) for the current scope and next decisions. The [20 game market review](docs/research/teen-game-market-review.md) evaluates teen audience signals, Roblox experiences, mobile successes, and opportunities for VRSchool. Its [citations and methodology](docs/research/citations.md) are maintained separately. Specialist [game designer](docs/research/game-designer-notes.md) and [art direction](docs/research/art-direction-notes.md) assessments accompany the review.

The documents were exported from Google Drive on October 29, 2026. Original imports are preserved in [the source archive](data/archive/2026-10-29-pre-gender-update/). Working documents now use the current faculty identities: the Brass Dragon and Gnoll are female (she/her), and Oobleck is non-binary (they/them). See the [gender record](data/faculty-gender-canon.json) for the revision shared by art, writing, and voice work.

## Working with this repository

Edit the Markdown documents directly to evolve the concept. Keep editable artwork in `assets/source/` and production media in the corresponding `production/` folder. The `.gitkeep` files retain currently empty folders in Git.

The spreadsheet, Photoshop asset, and raster concepts are stored as binary files. Keep concept iterations distinct from approved production assets.
